# tj-shoh-portfolio
# ⚡ Digital Business Card: TJ - SHOH

Хуш омадед ба саҳифаи расмии визиткаи рақамии **TJ - SHOH**. 

Ин лоиҳа як визиткаи муосир ва минималистӣ мебошад, ки махсус барои муаррифии фаъолият ва робита бо **TJ - SHOH** дар фазои интернетӣ сохта шудааст.

## 🚀 Дар бораи лоиҳа
Визиткаи рақамӣ имкон медиҳад, ки муштариён ва пайравон ба осонӣ бо TJ - SHOH тамос гиранд. Тарҳи лоиҳа дар услуби **Dark Gaming** бо рангҳои неони бунафш ва кабуд таҳия шудааст, ки ба фаъолияти муштарӣ мувофиқат мекунад.

## 🛠 Технологияҳои истифодашуда
Лоиҳа бо истифода аз стандартҳои муосири веб сохта шудааст:
* **HTML5** – Барои сохтори асосии саҳифа.
* **CSS3** – Барои тарҳрезии услуби геймингӣ ва аниматсияҳо.
* **Responsive Design** – Саҳифа дар ҳама намуди дастгоҳҳо (телефон, планшет, компютер) комилан дуруст намоиш дода мешавад.

## 🔗 Пайвандҳои фаъол
Шумо метавонед тавассути тугмаҳои зер бо мо дар тамос шавед:
* 📱 **WhatsApp** – Барои паёмҳои зуд ва ҳамкорӣ.
* 🎵 **TikTok** – Барои тамошои видеоҳо ва фаъолияти TJ - SHOH.
